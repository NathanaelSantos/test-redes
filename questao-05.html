O que preencher em cada exercício

Para cada cenário é dado um IP de host e o CIDR (o IP do host já vem preenchido — complete máscara, rede, 1º/último host e broadcast). A equipe deve identificar:

  • Endereço IP (host) — o IP do enunciado
  • Máscara — decimal (ex. 255.255.255.0) ou /24
  • Endereço de rede — network address
  • Primeiro host e último host utilizáveis
  • Broadcast

Valide cada um. Quando os 3 estiverem corretos, envie o resultado.
