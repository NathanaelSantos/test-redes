Questão 7 · Listar sub-redes

Dada a rede base, enumere todas as sub-redes iguais
← Início
✓
Os 3 cenários estão corretos e o resultado foi enviado ao painel do instrutor.

O que fazer

Em cada cenário é dada uma rede base e o novo CIDR (divisão igual / FLSM). Liste todas as sub-redes na ordem, da menor para a maior, preenchendo:

  • Máscara de cada sub-rede (igual para todas)
  • Endereço de rede, 1º host, último host e broadcast
Quantidade de sub-redes = 2(novoCIDR − baseCIDR) · Tamanho do bloco = 2(32 − novoCIDR) · Próxima rede = rede atual + tamanho do bloco
0 / 3 cenários corretos Pronto para enviar.
